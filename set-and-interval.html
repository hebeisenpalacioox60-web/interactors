区间表示法 vs 描述法（不等式）实时对照

集合名称 区间表示法 描述法（不等式语言）
集合 A [-4, 2) { x | -4 ≤ x < 2 }
集合 B (-1, 5] { x | -1 < x ≤ 5 }
当前运算 (A ∩ B) (-1, 2) { x | -1 < x < 2 }
核心口诀：交集取公共（且），并集取全部（或），补集取剩余（且不属于）。 端点原则：实心点 [ ] 对应 ≤ , ≥；空心点 ( ) 对应 < , >；无穷大 ±∞ 侧永远用开区间小括号。
